# App Specification: Pendiente (Tasks & Habits) ## 1. Today Screen (Main View) - **Top Calendar Slider:** Horizontal date picker. Today is selected by default. Supports scrolling to past/future days. - **Categorized Feed:** - Google Calendar events (expandable/collapsible). - Habits (frequent recurring activities). - Tasks (scheduled for the date, flexible timing). - **Floating Pomodoro Timer:** Visible if active. ## 2. Create Task (Action Sheet) - **Fields:** Title, Brief Description. - **Dynamic Subtasks:** Add new subtask on "Enter". - **Interaction:** Bottom sheet modal. ## 3. Pomodoro Timer - **Function:** Applicable to any activity (study, gym, work). - **Global Persistence:** Floating timer overlay across all views. - **Background Support:** Active even when the app is minimized. ## 4. Settings - **Language Selector:** System Default, Spanish, English. - **Theme Toggle:** Light / Dark mode. - **Integrations:** Google Calendar connection status.
